# Music Career Specification — status: FIRST HOOK ONLY

Implemented: Mission 4 grants `music.first_demo` and `item.song.first_demo`; Tone is the recording gatekeeper.

**Planned flow:** select beat → concept → structure → record takes → review → layers/ad-libs → mix → master → save the
song (a `SongInstance` with quality derived from attributes and choices) → release as Freestyle/Single/Mixtape/EP/Album/
Collab/Surprise/Compilation → promotion → weekly simulation of streams, downloads, sales, followers, playlists, radio,
shows, loyalty and revenue (revenue posted via `FinessBank`).

**Attributes:** Lyricism, Delivery, Creativity, Song structure, Recording, Performance, Branding, Industry knowledge.
**Studios:** home → neighborhood (Tone) → professional → personal → label HQ.
**Contracts:** advance, split, master ownership, length, obligations, release requirements, exit conditions;
negotiate / accept / reject / go independent.
**Rivalry:** diss tracks affect fans, relationships, opportunities, crew politics, Public Image and revenue without forcing violence.
**Audio:** original or licensed only. No copyrighted lyrics or recordings.
